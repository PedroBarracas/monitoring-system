Node.js e-commerce monitoring system that scrapes 50+ online stores (Portugal, Spain, France, Germany, Netherlands, Switzerland) for One Piece Card Game and Pokemon products.

**Why:** Track product availability and new listings across international retailers, notify via Discord webhooks.

**How to apply:** This is a scraping/notification system — changes typically involve adding stores, improving extraction accuracy, or fixing false positives. The extraction pipeline (JSON-LD → CSS → Heuristic) and detail-page stock verification are the most critical code paths.
